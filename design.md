# UI / UX Design System Specification

## Color Palette & Theme Tokens

### Brand Logo Accent (CTA)
- **Primary CTA**: `#E8521A` (Ember Orange / Logo Color)
- **Primary Foreground (Button Text)**: `#FFFFFF` (Bold Pure White)
- **Primary Hover**: `#D44312` with glowing shadow `0 8px 24px rgba(232, 82, 26, 0.35)`
- **Accent Glow**: `rgba(232, 82, 26, 0.12)`

### Clear Dark Typography
- **Headings & Core Text**: `#0A0A0C` (Clear Black Dark, high contrast)
- **Body Text**: `#1E293B` (Ultra legible dark text)
- **Muted Text**: `#334155` (Crisp dark slate for secondary info)

### Pure White Cards & Section Visibility
- **Card Background**: `#FFFFFF` (Pure Crisp White)
- **Card Border**: `1px solid rgba(15, 23, 42, 0.12)` (Sharp visible grid lines)
- **Card Shadow**: `0 4px 16px -2px rgba(0, 0, 0, 0.08), 0 2px 6px -1px rgba(0, 0, 0, 0.04)`
- **Section Band Backgrounds**: `#F4F5F8` & `#EEF2F6` (Light subtle backdrop allowing pure white cards to pop distinctly)

## Mega Menu & Navigation System
- **Interactive Tab Switching**: Hovering category tabs (Disposable Vapes, Pod Systems, E-Liquids) dynamically reveals only that category's brands in a multi-column side-by-side grid, hiding non-selected categories.
- **Card Styling**: High-contrast brand monograms with gradient backgrounds, badge pills (`HOT`, `15K PUFFS`, `TOP`, `NEW`), model subtitles, and arrow reveals.
- **Featured Spotlight**: Dedicated promotional card highlighting active category with trust badges, 3-hour Dubai delivery promise, and direct category CTA.
- **No AI Aesthetic**: Avoids generic single-letter boxes and bland columns; uses stylized monograms, refined typography, and verified authenticity indicators.
